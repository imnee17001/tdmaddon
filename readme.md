# ACE – All Cards Engine 1.8.5

**ONE CARD × INFINITE CARDS**

ACE (All Cards Engine) is a multi-mode Lovelace card for Home Assistant.  
One powerful engine that creates many different cards:

- **Display** – clean sensor value + icon
- **Thresholds** – color & label driven by the lowest value
- **Boolean** – multi-entity conditions with AND/OR logic
- **Graph** – history sparkline
- **Notes / Task Manager** – lightweight notes and checklists
- **Solar** – solar production & monitoring

And more modes are being added.
